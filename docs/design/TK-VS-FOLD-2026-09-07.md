## Findings
1. **Engine version stamp is still 0.5.65** on the fold; the toolkit's version fallback assumes 0.5.66+ for background launch. Must bump before release.
2. **Six ops missing from the fold** (exactly what the skew warning said): Navigate (`feat/navigate-op`), the spatial suite (PR #158), Starcast (PR #147). Plus headless worker (PR #155) which the toolkit's `src/core/headless/` layer targets. "Everything on one branch" = fold + #155 + #158 + #147 + navigate-op rehomed onto 4.7.2.
3. **Toolkit discovery is pointer-only without a project handle.** Attempt 1 launched with `--summer-no-publish`; the engine wrote only its instance-registry file and the toolkit reported "not running" on every call. `EngineApiClient.connect()` uses the registry only when given a selection (`--project`). Background/parallel instances need either the pointer or `--project`.
4. **`summer create` has no network timeout**: attempt 2 hung 42 min inside the template fetch.
5. **`summer run` has no engine-binary override**; it cannot launch a non-installed build. `SUMMER_BIN` is honored by the autopilot scaffold only.
6. One engine-side `ERROR: HTTPRequest is processing a request` during the run (engine's own HTTP client reuse); not toolkit-caused.
7. Two earlier attempts today failed on plumbing (3, 4), not on any tool. Per-tool behaviour was clean once the engine was reachable.
