Generated by `scripts/generate-registry` from `library/**/resource.yaml`:

- `registry/generated/plugin.claude.json` -> `.claude-plugin/plugin.json`
  (plugin manifest: full skill list at `./library/skills/<slug>/`, hooks,
  MCP pointer, userConfig; version stamped from `package.json`).
- `registry/generated/marketplace.claude.json` -> `.claude-plugin/marketplace.json`
  (marketplace listing wrapper).

The MCP pointer `./.mcp.json` these manifests reference is generated as
well (`registry/generated/mcp.json -> .mcp.json`, owned by the claude target).

Never edit the destination files by hand — edit `library/` resources or the
manifest builders in `scripts/generate-registry/manifests.ts`, then run
`npm run generate:registry`. CI `--check` fails on any drift.
