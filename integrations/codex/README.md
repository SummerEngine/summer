# Codex integration

Generated by `scripts/generate-registry` from `library/**/resource.yaml`:

- `registry/generated/plugin.codex.json` -> `.codex-plugin/plugin.json`
  (plugin manifest with the Codex app-store `interface` block; full skill
  list at `./library/skills/<slug>/`; version stamped from `package.json`).

- `registry/generated/mcp.codex.json` -> `.codex-plugin/mcp.json`
  (the plugin's two servers: `summer-engine`, the desktop-app bridge, and
  `summer-cloud`, Summer's hosted server).
- `registry/generated/marketplace.codex.json` -> `.agents/plugins/marketplace.json`
  (Codex's marketplace file; Codex reads it before `.claude-plugin/marketplace.json`,
  so it keeps the name `summer-engine`).

Install: `codex plugin marketplace add summerengine/summer`, then
`codex plugin add summer@summer-engine`.

Never edit the destination file by hand — edit `library/` resources or
`scripts/generate-registry/manifests.ts`, then run
`npm run generate:registry`. CI `--check` fails on any drift.
