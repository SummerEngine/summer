# Cursor integration

Generated by `scripts/generate-registry` from `library/**/resource.yaml`:

- `registry/generated/plugin.cursor.json` -> `.cursor-plugin/plugin.json`
  (Cursor plugin manifest: displayName/publisher/category, cursor-specific
  hooks file `./hooks/hooks-cursor.json`, full skill list at
  `./library/skills/<slug>/` — the pre-v3 four-skill gap was a bug and is fixed
  by generation; version stamped from `package.json`).

The MCP pointer `./.mcp.json` these manifests reference is generated as
well (`registry/generated/mcp.json -> .mcp.json`, owned by the claude target).

Never edit the destination file by hand — edit `library/` resources or
`scripts/generate-registry/manifests.ts`, then run
`npm run generate:registry`. CI `--check` fails on any drift.
