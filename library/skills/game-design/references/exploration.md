# Exploration, puzzles and suspense

Draw the intended dependencies on one page and the traversable spaces on another. Knowing *what* to do, knowing *where* to go, and being able to get there can fail independently. Account for what a first-time player has actually seen and for clues that arrive in an unexpected order.

| Genre and question | Small experiment and decision |
|---|---|
| **Logic puzzle.** Does a new rule need a tutorial? | Give the player one small puzzle that can only be solved using the rule. Then change the arrangement and watch whether they can predict its effect. An accidental first solution followed by failure is grounds to test a clearer example. Preserve the discovery if they transfer the rule unaided. |
| **Escape room.** Does the room need a hint system? | Ask each team to describe the next inference at its first stall. If teams already name the correct action but cannot find the one prop that accepts it, test that connection. Offer one optional hint at the reasoning step only if the inference itself keeps breaking down. |
| **Detective / deduction.** Is an ending guessed or earned? | At the accusation, ask players to show one clue that distinguishes their suspect from a plausible rival. Change the order of the existing clues for another group. Repeated correct guesses without a distinction suggest testing a discriminating clue. Ambiguity can stay if arguing several readings is the promise. |
| **Point-and-click / parser adventure.** Is the puzzle hard or is the interface rejecting a reasonable action? | Collect three attempted solutions verbatim at one gate. If different players express the intended idea using an unsupported verb or object, try accepting that expression or supplying a specific response. If they never infer the idea, test a clue earlier in the causal chain. |
| **Metroidvania.** Is returning with a new ability a reward or a memory test? | Show a blocked route before granting an ability. On the return trip ask players to mark where it might help before opening a map. Correct prediction plus a lost route suggests a landmark or shortcut. Wrong predictions point to the relationship between the ability and the obstacle. |
| **Open-world exploration.** Does the game need more map markers? | Give fresh players the same distant destination and listen to their route plan at a fork. Highlight one existing landmark and observe recovery after a detour. Keep optional wandering when players can recover and value the detour. Test a marker only where the world cannot carry the needed information. |
| **Stealth.** Is uncertainty producing tension or random-feeling detection? | After one detection, ask which cue warned the player and which surface offered cover. Re-run the same route with one clearer change of enemy alert state. If players now make different plans, preserve the threat. If their prediction was already correct, inspect detection and cover rules. |
| **Survival horror.** Does retreat preserve fear or devolve into repeating a solved sequence? | Save just before a threat and shorten only the walk back after failure. Compare route choices and players’ accounts of anticipation on the next attempt. If repetition falls and fear remains, keep the shorter retry. If the return was when dread built, test a different checkpoint. |
| **Walking simulator / environmental narrative.** Would another objective improve the scene? | Let a player leave the scene freely. Afterwards ask what they think changed and what in the room suggested it. If the intended interpretation is available but the player chooses a different one, preserve room for interpretation. If nobody notices the one object the next scene depends on, restage that object before adding a task list. |
| **Dungeon crawler.** Are generated branches offering decisions? | Hold the start equipment fixed and sketch the first consequential decision on several seeds. If different corridors repeatedly amount to the same safe pickup, author one visible risk-and-reward branch and compare. Retain maze-like disorientation if navigation and recovery are themselves the challenge. |
| **Immersive sim.** Does the level support experimentation when a plan goes wrong? | From one saved objective, try the obvious method, then a different action already supported elsewhere in the world. Check whether each produces a readable change and whether either allows recovery. Preserve authored constraints when players can infer them. If a familiar affordance silently stops working only here, test a consistent response. |

**Check what survives localization.** A station attendant asks for a part that can “hold its ground” on a shaking table. If one version of the line suggests a heavy object and another suggests a brave character, players have different evidence despite the same accepted part. Ask a fresh player using each shipped language to retell the request and show what they would try first. If a reading depends on the idiom, test a loose piece rattling on the table as an additional clue.

**Give the player enough evidence to make a plan.** In a night archive, let players see a patrol's lamp swing across the next aisle before they leave cover. Ask where they intended to cross and what risk they expected. An actionable plan can support preserving uncertainty about how long the gap will last. An unexplained detection after a correctly read cue calls for a replay from the same patrol state.
