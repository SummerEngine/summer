# Strategy, cards and tactics

Reconstruct a turn from information the player had at the time. List the viable alternatives, the commitment each demands, and when the opponent can respond. A losing choice can still be interesting. An apparent alternative that the player can never afford offers little agency.

| Genre and question | Small experiment and decision |
|---|---|
| **Turn-based tactics.** Do repeated reloads reveal unfair odds or a poorly communicated consequence? | Save one contested turn. Before resolution, ask players to predict the cover interaction, damage range, and enemy response in their own words. Reveal one missing forecast and replay another turn of similar difficulty. If predictions improve but losses continue by deliberate risk, preserve the risk. |
| **Real-time strategy.** Does an early resource lead remove counterplay? | Replay two plausible openings from swapped starting positions. Delay one reinvestment payout on a test map. Watch when the trailing player last had an affordable response. If that window reopens, tune the payout. If the match was decided before the investment matured, inspect scouting or the first engagement. |
| **4X / grand strategy.** Does a long campaign need additional events? | Take a midgame save and ask the player which of two plausible long-term plans they could still pursue. Compare skipping three turns with intervening on each. If interventions repeatedly have no effect, change one commitment or information deadline. If choices matter but feedback arrives too late to connect, test a forecast. |
| **Tower defense.** Does one tower dominate or is the next wave unreadable? | Offer the same budget and layout against two contrasting waves. Reveal the second wave's relevant property before purchase. If players now choose different defenses and can explain the difference, improve the forecast. If the same affordable tower still solves both, compare its coverage and opportunity cost. |
| **Auto-battler.** Can players connect the preparation phase to a battle outcome? | Show a short replay with the opening formation frozen. Ask for one repositioning prediction and replay from that state. If position reverses the exchange but players cannot see how, surface the key interaction. If no plausible position changes it, inspect the matchup or preparation options. |
| **Deckbuilding roguelike.** Is a card reward a meaningful deck decision? | Offer the same three cards before and after adding a way to exhaust or remove one starter card. Let players skip freely and ask what next draw each hopes to improve. If identity emerges from a smaller deck, test removal availability before enlarging the card pool. If players already pick for distinct plans, keep the reward set. |
| **Collectible / constructed card game.** Does a disliked matchup need a balance patch? | Replay from fixed opening hands, swap sides, and expose a plausible counter in a later trial. If the counter depends on information or cost the targeted decks rarely have, investigate timing and access. If it works once learned, test discovery before changing card values. |
| **Drafting / auction.** Is passing ever a decision? | Return players to the same offer with the same holdings, then change only what is known about the next offer or another bidder. If values change and players deliberately pass, the choice has stakes. If everyone always takes the first option, inspect scarcity and what passing preserves. |
| **Three-player conflict / area control.** Is the result decided by someone who has lost their own path to victory? | Replay a late position from each seat and ask which moves improve that seat's own standing. If one player can only choose the winner, test a continuing objective for that seat. If the table values negotiated endings, ask whether this is the social payoff before changing the rules. |
| **Wargame / scenario simulation.** Would more detail improve the scenario? | Name the command decision the scenario promises. On paper, collapse one logistical step and replay the same opening from both sides. If timing, information, and the decision survive while handling time falls, simplify. Keep detail whose removal makes a previously risky commitment automatic. |
| **Match-three / tile puzzle.** Can players make a plan under a short deadline? | Start from a board with one shuffle available. Ask players to choose whether to spend it on a blocked color now or save it for a second board. Keep the clock and move rules fixed. Show the second board and its required color before the first match in one trial. If players start saving the shuffle for a specific reason, test the preview in a fresh pair of boards. If saving always wins, give an opening board where the shuffle can protect more than it could later. |
| **Creature collector / team battler.** Does the bench give players a useful alternative? | Offer two creatures at equal power. One can interrupt a windup. The other can absorb one hit aimed at an ally each round. Give players a charge-up opponent and then a group that splits its attacks among allies. Ask which creature they would bring and what they expect it to change. If both roles matter but swapping never pays, test the swap cost before adding more creatures. |

## Winter delivery

A courier has 4 fuel on Monday. The express route spends 3 fuel and earns 4 points. The local route spends 1 and earns 2. On Tuesday, a service call worth 5 points requires 2 fuel and comes before the next refuel. When the call is on the calendar, the local route leaves enough fuel to earn 7 across both days. When there is no call, the express route earns more.

Replay the same Monday with the calendar visible before route selection and with the Tuesday call announced later. Ask which route the player would take and how much fuel they expect to have on Tuesday. Include a week with no call to see whether the choice changes with the forecast. If players take the local route when the call is known and the express route when it is absent, show the existing calendar at the decision. If they knowingly forgo the call, ask how they value Tuesday’s work before adjusting the payout.
