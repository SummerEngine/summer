# Action, movement and timing

Locate the failed action. Did the player see an opportunity, choose a response, execute it, then recognize the outcome? Replaying the same input can expose a rules or timing issue. A fresh player's account is more informative when the question is whether a cue made sense. Keep the relevant device, display and input conditions in the comparison.

| Genre and question | Small experiment and decision |
|---|---|
| **Platformer.** Is the first jump unreadable or too exacting? | Ask a player to point out the landing before their first attempt. If they choose correctly and repeatedly miss the same edge, change one margin on a copy of that jump. If they aim for the wrong ledge, test its silhouette first. Keep the original timing if it already supports the intended mastery. |
| **Endless runner.** Are players learning the obstacle language or memorizing deaths? | Move one familiar obstacle into a fresh sequence at the same speed. Change its preview distance on a second version. If anticipation improves on unseen sequences, tune the preview. If players predict the move but cannot execute it, inspect the input window. |
| **Arena shooter.** Does the losing player have a decision after respawning? | Replay one game map from two spawn locations and trace time to a *chosen* route or engagement. If the same opponent can deny every exit before the player sees them, test one revised spawn. If both routes work and players keep choosing the risky one knowingly, investigate the intended trade before changing the map. |
| **Tactical shooter.** Does one approach dominate because of information or reward? | In a graybox objective room, swap the location of one piece of objective information while keeping routes and scoring fixed. If both teams shift their approach, the placement matters. If nobody can describe the alternatives even after replay, test route readability. |
| **Bullet hell / shoot ’em up.** Is a wave demanding pattern reading or hiding the relevant collision boundary? | Repeat a short pattern with the same projectile paths and one clearer player hit indicator. Watch whether players can predict which near misses are safe. If predictions improve but dodging still fails as intended, preserve the pattern. |
| **Fighting game.** Is a repeated move dominant or is its counter undiscoverable? | Give matched players a saved situation and alternate sides. First let each propose a response, then show one legal counter and replay. If the counter works on reaction only for experts, test the intended audience’s recognition or execution window before changing damage. |
| **Character action / brawler.** Does a larger move list add a meaningful choice? | Give a player two existing moves against a crowd and against one armored enemy. Watch whether spacing, recovery, or interruption makes them switch. If both encounters reward the same move, vary one enemy response before prototyping a new combo tree. |
| **Rhythm.** Is a miss caused by timing, reading, or device delay? | Repeat one phrase with an uncluttered cue, compare audio and visual timing where available, and inspect early/late errors on the same device. A stable offset across a familiar phrase warrants a calibration check. Errors concentrated at novel syncopation point toward teaching or chart readability. |
| **Racing / time trial.** Does the racing line need an assist? | Keep the car and corner fixed. Ask where players expect to brake and add one visible landmark to a duplicate corner. If they can now choose braking points and improve across laps, keep the landmark. Test handling feedback if they already choose the point and cannot predict the car’s response. |
| **Sports.** Does the player need another control while off the ball? | Replay one restart from the same formation. Let a player signal the intended passing lane before acting. If the lane closes before a teammate can respond, test one teammate movement cue. If players already produce and read openings, preserve the current controls. |
| **Score attack / arcade time trial.** Does a drop in replay mean the mode fell flat? | Offer a rematch with the unlock already earned and a personal best to chase. Ask what the player would do differently. Someone who can describe a satisfying finish and prefers to stop has given a different signal from someone who wanted another run but saw no route to improve. |
| **Soulslike / boss rush.** Does a repeated death teach another response? | Resume just before the attack that ended the last attempt. Ask the player to anticipate it and try a different response, then restore the normal retry route. If practice at the move changes later choices, test access to that practice. If the player reads it correctly but lacks a feasible response from their prior position, inspect the earlier commitment. |

**Practice the condition that matters.** In a rooftop courier prototype, use a high nearby ledge and a low distant ledge to check whether players can choose different approaches to the same jump. In a shield duel, have the practice partner attack, then change its interval in a fresh encounter. In both cases, ask what the player expects before the crucial input and watch what they try when the original arrangement is gone.

**A platformer-specific test.** Start a jump from the same spot and at the same speed in both tests. Keep its controls, camera and target fixed. Change only the movement before the approach. In one version the player descends from a springboard and in the other they cross a low step. Ask how the unchanged jump feels and which part of the motion gave that impression. If descriptions track the preceding movement, keep the controller and tune the sequence. If the player cannot see the landing before committing, test camera framing separately.
